# Лабораторна робота №2 — Чисельні методи

**Тема:** Точне та наближене розв'язування систем лінійних алгебраїчних рівнянь
**Варіант:** 7
**Команда:** Данік, Саша, Степан, Тарас

## Завдання

**Завдання 1.** Розв'язати СЛАР точними методами (Крамера, Гаусса з вибором головного
елемента у стовпці, матричним, LU-розкладу):

```
 2x1 +  x2 + 4x3 + 3x4 = 9
 3x1 -  x2        + 2x4 = 4
-2x1 +  x2 + 4x3 +  x4 = 5
 3x1 +  x2 + 2x3 - 5x4 = 6
```

**Завдання 2.** Знайти наближений розв'язок з точністю ε = 10⁻⁴ методом простої ітерації
та методом Зейделя:

```
x1 =  0.14x1 + 0.31x2 - 0.17x3 + 0.21x4 - 1.73
x2 = -0.218x1         + 0.32x3 + 0.19x4 + 0.61
x3 =  0.32x1 - 0.15x2 + 0.05x3 - 0.17x4 - 0.88
x4 =  0.11x1 + 0.25x2 - 0.13x3          + 0.96
```

## Правила

1. Кожен редагує **тільки свої файли**: так не буде конфліктів.
2. Дані беремо з `data.py`, допоміжні функції — з `utils.py`.
3. Назви функцій і що вони повертають **не змінюємо**: на них розраховує `main.py`.
4. Кожна функція друкує проміжні кроки (для звіту) і повертає розв'язок.
5. Перед роботою `git pull`, після роботи `git add` → `git commit` → `git push`.
